## 🚀 Deploy to GitHub Pages

1. Fork or clone this repo
2. Rename `StudyNest.html` → `index.html`
3. Go to **Settings → Pages**
4. Set source to `main` branch, root folder
5. Click **Save** — your site will be live in ~60 seconds
